# My HVAC Trainer — Version 1

This is a free personal HVAC learning app.

## Included

- Eight detailed HVAC lessons
- Built-in diagrams
- Practice quiz
- Ohm’s Law calculator
- Superheat calculator
- Subcooling calculator
- Airflow estimate calculator
- Personal notes
- Saved progress
- Dark mode
- Offline support after the first visit

## Open it

### On a computer
Unzip the folder and open `index.html`.

### On an iPhone
The easiest method is to upload the folder to a simple static website host such as GitHub Pages, Netlify, or Cloudflare Pages. Then open the website in Safari, tap Share, and choose **Add to Home Screen**.

Opening a local HTML file directly on iPhone may limit offline features.

## Important safety notice

This app is educational. Always follow manufacturer instructions, wiring diagrams, EPA requirements, local codes, and proper lockout/tagout procedures. Never bypass a safety control.
